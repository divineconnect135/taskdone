# TaskDone

TaskDone is a responsive task management application built with vanilla JavaScript. It allows users to create, organize, filter, update, and manage tasks through a clean drag-and-drop interface.

The project focuses on core JavaScript concepts such as DOM manipulation, event handling, modular code structure, local storage, and browser drag-and-drop functionality without relying on a frontend framework.

## Live Demo

[View Live Demo]([ADD_YOUR_LIVE_DEMO_URL_HERE](https://taskdone-one.vercel.app/))

## Features

- Create new tasks
- Edit existing tasks
- Delete tasks
- Organize tasks by status
- Drag and drop tasks between sections
- Filter tasks
- Persist tasks using `localStorage`
- Responsive layout for desktop and mobile
- Form validation
- Empty-state handling
- Modular JavaScript structure

## Built With

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Browser Drag and Drop API
- LocalStorage
- ES Modules
